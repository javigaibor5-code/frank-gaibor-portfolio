# 🌐 Personal Portfolio Website

Third project of my portfolio as a Software Development student. A simple,
responsive personal website built with **HTML, CSS, and vanilla JavaScript**,
used to present myself, my skills, and my other projects to recruiters and
potential clients.

## 🔗 Demo
[View live site](#) <!-- Replace with your GitHub Pages link -->

## ✨ Features
- Responsive design (desktop, tablet, and mobile) with a collapsible mobile navigation menu
- Sections: Hero, About, Skills, Projects, and Contact
- Direct links to my other two portfolio projects (Calculator and Inventory CRUD)
- Smooth scrolling navigation

## 🛠️ Technologies
- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, responsive design, sticky navigation)
- JavaScript (mobile menu toggle, dynamic footer year)

## 📚 What I learned
- Structuring a multi-section website with semantic HTML
- Building a responsive layout without any CSS framework
- Small but meaningful JavaScript interactions (menu toggle, DOM updates)
- Presenting technical work in a way that's clear for a non-technical audience (recruiters, clients)

## 🚀 How to run it locally
1. Clone this repository
2. Open `index.html` in your browser (no installation or dependencies required)

## ✏️ Before publishing
Remember to replace the placeholder email and LinkedIn link inside `index.html`
(in the Contact section) with your real contact details.
